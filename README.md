# FoodSave Campus

**OneCore · Кәржан Ержігіт · Smart Food Industries, 1-трек**

FoodSave Campus асхана қызметкеріне тағам қалдығын өлшеуге, оның себебін жазуға және 100 порцияға қанша қалдық келетінін көруге көмектеседі. Ай соңында тексеруші есепті бекітеді. Бес бөлімшенің бекітілген жазбалары бір тізімге жиналады.

## Қазылар алқасына

- [Қазақша таныстырылымды ашу — PDF, 11 слайд](docs/presentation/FoodSave-Campus-KK.pdf)
- [PowerPoint нұсқасын жүктеу — PPTX](https://github.com/yerzigitkarzan-pixel/foodsave-campus/raw/refs/heads/main/docs/presentation/FoodSave-Campus-KK.pptx)
- [Демонұсқаны браузерде ашу](https://yerzigitkarzan-pixel.github.io/foodsave-campus/)

Демонұсқада қалдық салмағы мен порция санын өзгертіп көріңіз. Мысалы, 200 порциядан 3 кг қалдық шықса, 100 порцияға 1,5 кг келеді. Экономика мен CO₂ көрсеткіштері оқу мысалдары бойынша есептеледі. Демонұсқаны жүктелген жобадағы `showcase/index.html` файлын ашып та пайдалануға болады.

## Толық жүйені іске қосу

Толық нұсқада екі рөл, айлық есепті түзету мен бекіту, Excel-ге жүктеу, графиктер және жергілікті талдау бар. Жүйе Python 3.12, FastAPI және SQLite арқылы жұмыс істейді.

Windows жүйесінде жобаның негізгі бумасынан мына командаларды орындаңыз.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

Браузерде `http://127.0.0.1:8000` мекенжайын ашыңыз. Бірінші іске қосқанда жүйе үлгі деректер мен жергілікті кіру құпиясөздерін жасайды. Құпиясөздер терминалда көрсетіліп, `.local/DEMO_ACCESS.txt` файлына жазылады. Асхана қызметкері ретінде `iskander`, тексеруші ретінде `reviewer` логинін пайдаланыңыз.
